#狐狸·涌现·爱
悖论篇
​「Yablo悖论」，一个很有意思但并不广为人知的悖论，表述如下：
存在一个无穷序列，其中的每一项都声称后面的全部命题为假，则该序列中每一个命题的真假都无法判定。
​论证如下：若序列中所有命题均为假命题，则可得出序列中必有真命题，矛盾。若序列中存在真命题，不妨令第 n 项为真命题，则前 n-1 项为假命题，但对于 n 以后的项，由于 n 的宣称，它们全为假命题，又由于第 n+1 项为假命题，则 n+1 以后的项必有真命题，矛盾。
​对于这个悖论主要有两种理解：一是认为这依旧是「自指型悖论」的某种变体。事实上，「自指型悖论」的自环能通过添加元素以拓展为回路，且仍保存悖论的性质。而 Yablo 悖论的线性链条可以看成拥有无穷个元素的自环，从而与自指型悖论等价。另一种观点认为这并不构成悖论，而只是我们的思维不能很好地处理无穷。很显然，在元素有限的情况下，Yablo 悖论是可判定的（仅有最后一项为真）。也就是说，假若我们的思维能越过无穷（参考超任务），就能完成对该序列命题的判断。而早在三千年前，芝诺讲述的那个关于乌龟的故事就告诉我们，思维过程与客观过程不能画等号（追乌龟的思维过程是无限的，在这场思维赛跑中，我们永恒地追不上这只思维中的原乌龟。但客观的进程与此是完全不同的）。即我们可以认为，虽然我们将 Yablo 悖论思维为不可判定，但（客观上）该序列中的每一项的真假都是确定的。
